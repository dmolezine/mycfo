# Segurança

Dados financeiros são isolados por usuário com Row Level Security. O frontend utiliza apenas a chave publicável do Supabase.

Não adicione ao repositório:

- chaves secretas ou `service_role`;
- senhas de banco;
- tokens pessoais do GitHub;
- backups financeiros reais.

Relate vulnerabilidades de forma privada ao proprietário do repositório, sem abrir uma issue pública com dados sensíveis.
